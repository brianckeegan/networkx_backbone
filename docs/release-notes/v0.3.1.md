A patch release with one bug fix that changes results, a change in behavior,
new Monte Carlo tools for `fdsm`, a working conda workflow, and a second round
of documentation.

Upgrade with `pip install --upgrade "nx-backbone[full]"`.

## Change in behavior

- **`ecm_filter` raises when its fit does not converge.** It raises
  `networkx.ExceededMaxIterations`, naming the node furthest off, instead of
  warning and returning p-values that could be far off. Pass
  `nonconvergence="warn"` for the old behavior ([#144]).

## Changes in results (bug fixes)

- **`ecm_filter` converges on graphs with a heavy hub** ([#135], [#144]). The
  solver treated a node's own self-pair as a pair, so its line search
  stalled. It also now handles degree sequences that never allow some pairs
  to be linked, such as the ends of a 4-node path.
  - Where the old fit converged, p-values are bit-for-bit unchanged (Les
    Misérables: 72 edges).
  - On the graph of #135, the edges at p < 0.05 go from 21 to 1.
  - Across every graph of up to 7 nodes and 2,853 random digraphs, fits that
    fail to converge go from 1,055 to 0.

## New features

- **`fdsm` reports its Monte Carlo resolution** ([#76], [#145]).
  - Each pair gets a standard error (`fdsm_pvalue_se`) and a one-sided 95%
    upper bound (`fdsm_pvalue_upper`).
  - The graph records `fdsm_trials` and the p-value floor `1/(trials + 1)`.
  - `backbone_from_projection`, `backbone()` and `threshold_filter` warn,
    with the number of trials needed, when the floor makes significance
    unreachable at the requested `alpha` and correction. Before, the backbone
    simply came back empty.
  - P-values are unchanged.
- **`fdsm(refine="splitting")`** re-estimates p-values below the Monte Carlo
  floor by adaptive multilevel splitting on the curveball chain ([#77],
  [#146]).
  - Validated against exact p-values from 7e-3 to 1e-9: mean bias between −1%
    and +6%, upper-bound coverage 92–97%.
  - At p ≈ 1e-4, it is about 200 times cheaper per pair than plain Monte
    Carlo.
  - On the bipartite tutorial's planted block, Holm keeps 27 of 28 planted
    pairs instead of none.
  - Not yet available with `signed=True`. Without `refine`, results are
    unchanged.

## Documentation

- **Figures on every how-to and user guide page**, drawn when the docs are
  built, in light and dark ([#121], [#122]). A test keeps it that way.
- **Three new narrative tutorials:**
  - comparing, validating, and reporting backbones ([#123]);
  - directed and signed networks ([#124]);
  - what your weights mean: transforms, units, and checking calibration
    ([#125]).
- **One figure helper for every tutorial**, with computed alt text and
  captions ([#128]).
- **A test that recomputes the numbers quoted in the how-to and user guide
  prose** ([#137]). Two wrong numbers it found are fixed.
- **The old documentation address `/networkx_backbone/` redirects** to the same
  pages under `/nx-backbone/` ([#138]).

## Infrastructure

- **The conda workflow works again** ([#16], [#143]).
  - It no longer installs `conda-verify`, which has no build for Python 3.12.
  - A manual run with a `tag` input can publish an existing release tag.
  - This release's run uploads 0.3.1 to anaconda.org. The 0.3.0 package can
    be published with a manual run, `tag=v0.3.0`.
- **The interop CI works with xgi 1.0** ([#141]).
