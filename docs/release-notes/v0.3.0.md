This is the first release on PyPI since 0.1.0. (The `v0.2.0` tag never
reached PyPI: its `pyproject.toml` still set version 0.1.0. PyPI's
`0.2.0.post1.dev9` was a development build from `main`.)

**Several methods now return different results.** A full code review checked
every method against its paper and against R `backbone` 3.0.4 and `netbone`
0.2.3, and fixed the problems it found. Read *Changes in results* before
upgrading code whose output you have reported.

Install with `pip install --upgrade "networkx-backbone[full]"`.

## Highlights

- **Hypergraph backbones**: the parameter-free MDL hypergraph backbone
  (Kirkley et al., 2026) with global and local (per-node neighborhood)
  variants, statistically validated hypergraphs and cores (SVH/SVC), and
  adapters for xgi, HyperNetX, HypergraphX, HAT, and the HIF interchange
  format, tested against the real libraries
  ([#7], [#47], [#48]).
- **Two new statistical filters**: the Pólya urn filter (Marcaccioli & Livan,
  2019) and the GloSS filter (Radicchi, Ramasco & Fortunato, 2011)
  ([#50], [#51]).
- **Backbone 3.0 parity**: multiple-testing correction, signed backbones,
  SDSM-EC, and `missing_as_zero` for testing absent pairs
  ([#7], [#37], [#45]).
- **`describe_backbone()`** writes the methods-section text and BibTeX
  citations for any backbone ([#36]).
- **More inputs**: `to_graph()` and the `backbone*` wrappers accept NumPy and
  SciPy adjacency matrices and pandas edge lists; bipartite functions accept
  incidence matrices ([#39], [#46]).
- **Validated against reference implementations**: p-values and backbones are
  compared with R `backbone` 3.0.4 and `netbone` 0.2.3 on Les Misérables, the
  karate club, and Davis Southern Women ([#52]).
- **NetworkX backends**: the graph-in, graph-out functions are dispatchable,
  so they accept `backend=` and follow `nx.config.backend_priority`
  (for example nx-parallel for the shortest-path methods) ([#62]).
- **Faster**: sparse bipartite projections (3000x800: from 40-76 s to under
  2 s), and an ECM solver that fits a 2,000-node graph in under 2 s instead
  of about 90 s ([#39], [#53]).

## Changes in results (breaking)

Les Misérables counts are edges kept at the documented threshold (alpha =
0.05 for p-values); Davis counts are significant woman-woman pairs at alpha =
0.05. "Before" is 0.2.0.

| Method | What changed | Before -> after |
| --- | --- | --- |
| `disparity_filter` | p-value is now (1 - p)^(k-1) as in Serrano et al. (2009); 0.1.0 and 0.2.0 used the integrand of the formula instead of its integral ([e5f925c]) | 247 -> 9 edges |
| `noise_corrected_filter` | now the published Bayesian noise-corrected backbone (Coscia & Neffke, 2017), matching the authors' code; new `nc_sdev`, `nc_pvalue`; the old z-score is `method="zscore"` ([#37]) | 98 -> 195 edges |
| `multiple_linkage_analysis` | fits ideal dominance distributions by default (Van Nuffel, 2007); old behavior is `method="lans"`; new `deviation=` ([#37], [#41]) | 109 -> 205 edges |
| `ecm_filter` | the old solver never converged and kept every edge; now a maximum-likelihood fit ([#33], [#53]) | 254 -> 72 edges |
| `marginal_likelihood_filter` | Dianati's null; the old formula depended on node order ([#33]) | 70 -> 126 edges |
| `glab_filter` | per-node shortest-path involvement (Zhang et al., 2014) instead of global edge betweenness ([#33]) | 5 -> 56 edges |
| `lspar` / `sparsify` | each node ranks its own edges; ties kept together ([#33]) | 136 -> 174 edges |
| `local_degree` | same ([#33]) | 135 -> 91 edges |
| `h_backbone` | follows Zhang et al. (2018) ([#33]) | 22 -> 18 edges |
| `bicm` / `sdsm` | BiCM actually fitted; exact Poisson-binomial tails ([#33]) | Davis: 3 -> 0 pairs |
| `fdsm` | the null now preserves degrees ([#33]) | Davis: about 10 -> 5 pairs |

Also changed:

- `disparity_filter` and `lans_filter` on directed graphs also test the
  target's incoming links ([#33]; `lans_filter` by @bfs2021 in [#34]).
- `sparsify(umst=True)` adds the union of all minimum spanning trees, so ties
  no longer make the result depend on node order ([#35]).
- `doubly_stochastic_filter`'s `ds_weight` no longer depends on node insertion
  order when Sinkhorn-Knopp does not converge ([#54]).
- `high_salience_skeleton` splits credit among tied shortest paths;
  `fixedfill`/`fixedcol` use exact nulls; `metric_backbone` uses a relative
  tolerance; proximity indices exclude self-loops; `reachability` counts
  directed reachability correctly; `adjust_pvalues` keeps NaN as NaN
  ([#33]).
- `backbone_from_projection` and `backbone()` threshold `sdsm` and `fdsm` at
  `alpha` like the other models ([#33]).
- Functions that used a hardcoded `seed=42` now default to `seed=None`. Pass a
  seed for reproducible results ([#33]).
- Every scorer raises `NetworkXNotImplemented` for multigraphs and
  `NetworkXError` for missing, non-positive, NaN, or infinite weights
  ([#33]).

## New features

Statistical and structural:

- `polya_filter` ([#50]) and `gloss_filter` ([#51]).
- `signed=True` on `ecm_filter` and `noise_corrected_filter` ([#37]);
  `missing_as_zero=True` on the weighted scorers and `backbone_from_weighted`
  ([#45]).
- Directed `glab_filter` ([#35]).
- `doubly_stochastic_filter`: Slater's connectivity stage (`ds_keep`) and a
  `smoothing=` pseudocount ([#49], [#54]).
- `ecm_filter` scales to tens of thousands of nodes ([#53]).

Bipartite and hypergraph:

- Hypergraph module: MDL backbone, SVH/SVC, maximal hyperedges, order
  filtering, s-components, intersection graphs ([#7]);
  `local_mdl_hypergraph_backbone` ([#47]).
- `adjust_pvalues`, `threshold_filter(mtc=...)`, SDSM-EC, and new options on
  `sdsm`, `fdsm`, `bicm`, and `backbone_from_projection` ([#7], [#33]).
- `hyper_projection(newman=True)` for Newman's 1/(d-1) weighting ([#39]).
- `hypergraph_io`: HIF reader/writer and adapters for xgi, HyperNetX,
  HypergraphX, and HAT, carrying weights; new extras `[xgi]`, `[hypernetx]`,
  `[hypergraphx]`, `[hat]`, `[interop]` ([#7], [#48]).

Inputs, backends, reporting, and docs:

- `to_graph()` and matrix/DataFrame inputs to the `backbone*` wrappers
  ([#46]); NumPy, SciPy, and pandas incidence matrices in the bipartite
  functions ([#39]).
- Dispatchable graph-in, graph-out functions (`backend=`, dispatch names
  prefixed `backbone_`) and a backends user guide; CI runs the tests under
  NetworkX's `nx_loopback` dispatch harness ([#62]).
- `describe_backbone()` and the "Validating a backbone" tutorial ([#36]).
- `multigraph_to_weighted(aggregate=...)` ([#33]).
- A roadmap with generated status figures ([#33], [#56], [#57]), a coverage
  evaluation of the methods compared by Yassin et al. (2025) ([#40]),
  numpydoc-validated docstrings, an asv benchmark suite, and a Les Misérables
  table computed at build time ([#38]).
- `CITATION.cff` ([#36]).

## Supported versions

- **Python 3.12 or newer** and **NetworkX 3.4 or newer** (breaking), matching
  NetworkX's support window. Optional minimums: NumPy 2.2, SciPy 1.15,
  Matplotlib 3.10. CI tests Python 3.12-3.14, the oldest supported versions
  exactly, and a NetworkX-only install ([#33]).
- The `Development Status` classifier is now `4 - Beta` ([#66]).
